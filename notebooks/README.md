# Research Notebooks

This directory contains the original research notebooks developed as part of the MTech project.

## Notebooks

### 01_model_training.ipynb

Contains the main model development and training experiments for the fake news detection system.

### 02_cross_dataset_evaluation.ipynb

Contains the evaluation and analysis performed after model training, including cross-dataset evaluation.

## Purpose

These notebooks are retained as the original research implementation and experimentation record.

The production implementation will be separated into the following components:

- `src/` — machine learning and inference code
- `api/` — FastAPI backend
- `app/` — Streamlit frontend
- `tests/` — automated tests
- `scripts/` — utility and execution scripts
- `models/` — trained model artifacts
- `artifacts/` — generated outputs and evaluation artifacts

The original notebooks should be preserved and not modified during the productionization process.
